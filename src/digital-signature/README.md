# Электронная цифровая подпись (ЭЦП)

Демонстрационное приложение для электронной цифровой подписи на основе RSA алгоритма с клиент-серверной архитектурой.

## Структура проекта

```
digital-signature/
├── server/                 # Серверная часть (Node.js + Express)
│   ├── controllers/        # Контроллеры
│   ├── routes/            # Роуты API
│   ├── services/          # Бизнес-логика
│   ├── keys/              # RSA ключи
│   ├── package.json
│   └── server.js
└── client/                # Клиентская часть (React)
    ├── src/
    │   ├── api/           # API клиент
    │   ├── components/    # React компоненты
    │   ├── pages/         # Страницы
    │   └── App.jsx
    ├── public/
    └── package.json
```

## Запуск приложения

### 1. Запуск сервера

```bash
cd server
npm install
npm start
```

Сервер запустится на порту 3001.

### 2. Запуск клиента

```bash
cd client
npm install
npm start
```

Клиент запустится на порту 3000.

## Функциональность

### Сценарий 1: Подпись на стороне клиента

- Клиент генерирует RSA пару ключей
- Подписывает сообщение своим закрытым ключом
- Отправляет подписанное сообщение на сервер для проверки
- Сервер возвращает результат верификации

### Сценарий 2: Подпись на стороне сервера

- Клиент получает публичный ключ сервера
- Запрашивает у сервера подписанное сообщение
- Сервер генерирует сообщение и подписывает его
- Клиент проверяет подпись локально

## API эндпоинты

- `POST /api/signature/verify` - Проверка подписи
- `GET /api/signature/public-key` - Получение публичного ключа сервера
- `POST /api/signature/generate-message` - Генерация подписанного сообщения

## Технологии

- **Frontend**: React 18, Web Crypto API
- **Backend**: Node.js, Express, встроенный crypto модуль
- **Криптография**: RSA-SHA256, длина ключа 2048 бит

## Особенности реализации

- Использование нативных криптографических API (без сторонних библиотек)
- Полная поддержка двух сценариев ЭЦП
- Безопасная передача данных между клиентом и сервером
- Интуитивный пользовательский интерфейс
